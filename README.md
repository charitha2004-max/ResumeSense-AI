# 🎯 ResumeSense AI

### AI-Powered ATS Resume Analyzer

---

## 📌 Project Overview

ResumeSense AI is an AI-powered web application designed to help users evaluate and optimize their resumes against job descriptions.

The application analyzes uploaded resumes using Artificial Intelligence and provides ATS-style feedback including:

- ✅ Matching Skills
- ❌ Missing Skills
- 💪 Resume Strengths
- 💡 Personalized Improvement Suggestions

The system helps job seekers improve their resumes for better ATS compatibility and increases their chances of securing interviews.

---

## 🎯 Objectives

- Analyze resumes against job descriptions using AI
- Provide ATS-style resume evaluation
- Identify matching and missing skills
- Generate personalized improvement suggestions
- Simplify resume optimization

---

## 👤 User Features

- 📄 Upload Resume (PDF)
- 💼 Paste Job Description
- 🤖 Analyze Resume using AI
- 📊 View ATS Match Score
- ✅ View Matching Skills
- ❌ View Missing Skills
- 💪 View Resume Strengths
- 💡 Receive AI Suggestions
- 📥 Download PDF Report

---

## 🤖 AI Features

### 📊 ATS Resume Analysis

Compares the uploaded resume with the job description and evaluates compatibility.

### ✅ Skill Matching

Identifies skills present in both the resume and the job description.

### ❌ Missing Skill Detection

Highlights important skills or keywords missing from the resume.

### 💪 Resume Strength Analysis

Identifies strong areas within the resume.

### 💡 AI Suggestions

Provides personalized recommendations to improve ATS compatibility.
